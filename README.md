# StarRing

Source code for the StarRing website, published at [starring.edwinfredy.com](https://starring.edwinfredy.com).

This project is built using React, TypeScript, Three.js, React Three Fiber and Vite.

## Bright Star Catalogue

This project references stars via the <a href="http://tdc-www.harvard.edu/catalogs/bsc5.html">Bright Star Catalogue</a> (also known as Yale Bright Star Catalouge), and can be used to identify all objects with a magnitude of 6.5 or brighter, which includes 9095 stars, 11 novae or supernovae and 4 non-stellar objects. Stars are referenced in the BSC with the prefix '<b>HR</b>' (which stands for 'Harvard Revised').

The catalogue was originally published in 1908.
